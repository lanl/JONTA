# Security policy

JONTA is scientific simulation software. Please do not disclose a suspected
security issue in a public issue or pull request before maintainers have had an
opportunity to assess it.

Use GitHub's private vulnerability-reporting mechanism when it is enabled for
the repository. If that mechanism is unavailable, contact the maintainers
through a private GitHub channel and include:

- the affected commit or release;
- a minimal reproduction;
- the impact and any required conditions;
- a proposed mitigation, if known.

Do not include secrets, private datasets, or personal information in a report.

Security fixes should include a regression test where possible and a concise
entry in the changelog.
