# Slab benchmarks

Homogeneous momentum-space benchmarks isolate collision, acceleration,
radiation, and large-angle avalanche physics without radial orbit geometry or
plasma feedback.

Each case has an independent configuration, reference-data provenance, and
physical comparison figures. Selected cases include CPU scaling records;
remaining scaling studies, including GPU measurements, are pending.

The McDevitt avalanche cases are split into the accepted growth-rate scan in
[`avalanche_decay/`](avalanche_decay/) and the threshold scan in
[`avalanche_threshold/`](avalanche_threshold/).
