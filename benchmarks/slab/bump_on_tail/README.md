# Bump-on-tail / runaway-vortex benchmark

Small-angle collisions, parallel electric acceleration, and synchrotron
radiation are active. Large-angle collisions and plasma coupling are disabled.

Primary reference: Guo, McDevitt & Tang, *Plasma Physics and Controlled Fusion*
59, 044003 (2017). The benchmark compares the bump momentum, width, O/X-point
scaling, and the vortex disappearance threshold.

Reference values are in `reference/guo_2017_fig9.csv`. The driver and YAML
configuration are pending migration from the legacy validation driver.
