# Reference-data index

Reference data is stored next to the benchmark that consumes it. This
directory is retained only as a migration index; new data must not be added
here.

- [`../one_d/radial_transport/reference/`](../one_d/radial_transport/reference/)
  contains the McDevitt transport digitizations.
- [`../slab/bump_on_tail/reference/`](../slab/bump_on_tail/reference/) contains
  the Guo bump/vortex values.
- [`../slab/avalanche_decay/reference/`](../slab/avalanche_decay/reference/)
  contains the McDevitt avalanche digitizations.

The source PDFs are supplied as project reference material and are not copied
into the public repository. Each benchmark's `reference/metadata.yaml` records
the citation, DOI, source document, figures, and digitization provenance.
