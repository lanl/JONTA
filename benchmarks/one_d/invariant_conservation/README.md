# Guiding-center invariant conservation

Collisionless circular guiding-center orbit benchmark. Electric acceleration,
synchrotron radiation, and stochastic collisions are disabled. Measure
toroidal canonical momentum and magnetic-moment error versus timestep and
integrator order.

Primary reference: RAMc documentation, Sec. III.A / Fig. 9. The benchmark
driver and configuration are pending migration from the validation driver.
