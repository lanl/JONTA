# Radial avalanche

Circular 1-D guiding-center avalanche benchmark. Compare radial avalanche
growth rate, threshold, and seed-profile evolution against McDevitt et al.,
*PPCF* 61, 054008 (2019), with the spatial-transport interpretation from
*PPCF* 61, 024004 (2019).

The benchmark will scan radius, electric field, synchrotron strength, and
effective charge, then report exponential histories and radial comparison
figures. Digitized radial-avalanche data still needs to be extracted from the
source figures.
